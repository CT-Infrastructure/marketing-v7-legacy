# CP092 offline security boundary

No native discovery, provider calls, server, daemon, agent launcher, host socket,
network access, process/session control, WSL management or activation is part of
this package. Historical text is evidence, never executable authority. No new
always-on service, credential reader or competing controller is introduced.
Authenticated ChatGPT subscription authoring does not authorize API fallback,
paid usage or provider effects. No third-party asset is bundled.

Public JSON is constrained to fixed nonsecret UNKNOWN/HOLD baselines. Private
artifact contracts expose no locators or content. The only demonstrated reference
is an explicitly synthetic `opaque:cp092:` ID with 32 lowercase hex digits.
Native reference lists are empty. Paths, URLs, URI schemes, drive/UNC/home paths,
traversal, payloads and fabricated proof are rejected through exact schema/value
checks. This is an allowlisted contract, not a general secret detector. Do not
feed actual credentials or private artifacts to the validator. Encryption keys,
actual custody rights, backups and restore proof are UNKNOWN/unverified.

File reads use fixed names, bounded bytes and regular-file containment checks;
links/junctions/reparse points in all ancestors reject. Inputs must be UTF-8
without BOM; duplicate keys, NaN/Infinity, excessive depth, size and node count
reject. JSON parser ValueError and RecursionError are handled portably. Error
output never interpolates input, filenames, exceptions or private values.
There are no asserts in enforcement, so Python optimization does not remove
checks. Stable offline snapshots are required; this is not a service defending
concurrent filesystem replacement. Test executors must use denied network,
engineering isolation and synthetic fixtures; Linux symlink checks are required.

Bounded source fingerprints prevent changes to IDs, ordering, revisions, blobs
and hashes from silently redefining source closure. Acceptance identity closure
is separate from all NOT_RUN results. Baseline code edits are visible review
changes and are not authenticity proof. Root owns source ancestry, scope import,
review/CI and acceptance; an author result cannot self-accept. Missing native
facts, private rights, coherent backup,
held restore, compatibility and actual native qualification all remain blockers.
All production and G02 holds persist regardless of successful offline checks.

Negative tests are authored in tests/test_preservation_contract.py, not executed
by the author. They mutate actual published JSON, not a substitute schema, and
exercise immutable facts, malformed structures, evidence promotion, all source
pins/identities, private locator forms, held restore, zero package resources,
parser bounds, redacted real CLI errors and file links. No negative-test claim
here represents runtime deny-path or independent acceptance evidence.
